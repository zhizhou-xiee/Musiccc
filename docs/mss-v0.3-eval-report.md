# MSS/0.3 复测与路线决策

## 决定

第一版 MCP 的唯一默认音乐感知路线确定为：**预生成客观音乐摘要＋数值曲线**。

MSS/0.3 不作为默认返回格式。它保留为可复现实验产物，后续可以继续研究，但不会形成运行时动态路由、精度档位或降级链。

## 为什么没有因高分采用 MSS

最终候选对 GPT‑6 Luna、Claude Haiku 5.5、Gemini 3.8 Flash 各测试三次，共 9 次独立调用。10 道客观题的结果是：

| 模型 | 三次得分 | 均值 |
|---|---:|---:|
| GPT‑6 Luna | 10.0 / 10.0 / 10.0 | 10.00 |
| Claude Haiku 5.5 | 9.5 / 9.5 / 10.0 | 9.67 |
| Gemini 3.8 Flash | 10.0 / 10.0 / 10.0 | 10.00 |
| **跨模型** | 88 题完整正确、2 题部分正确 | **9.89** |

MSS/0.3 的平均分超过预设门槛 9.1667，实际音乐材料也只有 GPT 480、Claude 642、Gemini 642 token，低于三家共同的 800-token 上限。

但最终轮仍出现 **2 个明确的客观方向矛盾**，都来自 Claude 对 119.138 秒交接的反向复述。材料已经直接写成中文“横笛退出、古筝或琵琶候选进入”，其中两次回答仍写成古筝退出、横笛进入。预设门槛是不超过 1 个，因此严格判定失败。

上一轮客观自然语言＋曲线基线为 9.17 / 10，明确事实矛盾 1 个，满足安全门槛。默认路线因而选择该基线所属的候选 B，而不是为了 0.72 分均值增益放宽错误标准。

## Token 测量

这里不再使用 UTF‑8 字节代理冒充 token。每个模型的音乐材料 token 为同模型完整 prompt usage 减去相同系统提示、歌词和问题的仅歌词 prompt usage：

| 模型 | 仅歌词 prompt | MSS/0.3 prompt | 音乐材料差值 |
|---|---:|---:|---:|
| GPT‑6 Luna | 1,959 | 2,439 | 480 |
| Claude Haiku 5.5 | 2,449 | 3,091 | 642 |
| Gemini 3.8 Flash | 2,437 | 3,079 | 642 |

最终正式 run 为 9/9 成功、9/9 `finish_reason=stop`，输入 25,827 token，输出 7,448 token，OpenRouter 报告费用 `$0.01921253`。

MSS/0.3 从超预算草稿到三轮正式测试的全部 OpenRouter 调用合计 `$0.07460088`。加上上一阶段已报告的 `$0.14392706`，项目目前 OpenRouter 累计报告费用为 **`$0.21852794`**，没有其他新增付费资源。

## 默认摘要路线的约束

- 内容只能是可观察事实，不预写情绪、赞美或比喻。
- 数值曲线继续保留，使模型看到运动形状而不是只收到“激昂”“缓慢上升”等解释。
- 当前歌词、演唱者、基底、前景、乐器进入退出及不确定项保留来源与审核状态。
- 每次 MCP 调用只返回当前短段，不一次注入全曲。
- 自动曲线必须标为自动测量且未人工校验；不可靠的旋律、调性和拍号继续返回 unknown。
- 不宣称模型直接听见原始音频。

完整原始回答、manifest、候选快照、生成脚本和计分卡均位于 `data/songs/jieyue/experiments/mss-v0.3-poc/`。
