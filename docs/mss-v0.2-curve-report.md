# MSS/0.2 Curve-first PoC 报告

## 结论

MSS 的实验目标从“用自然语言概括音乐”调整为“保留尚未被预先解释的音乐运动”。MSS/0.2 的核心由客观离散事件、持续基底与当前前景的叠层关系、多变量时间序列、结构关系、来源与显式未知项组成；情绪标签、比喻和听后感不进入默认层。

自然语言仍负责歌词、演唱者、乐器名称和必要的来源说明，但不再负责把连续曲线翻译成“激昂”“舒缓”等解释。旧自然语言摘要保留为对照基线。

## 本轮测量

输入为已登记 SHA-256 的最终 MP3 母带。脚本完全离线运行，未调用模型、网络或付费资源。

|---|---:|
| 母带时长 | 249,594 ms |
| 时间窗 / 步长 | 500 / 500 ms |
| 曲线采样窗 | 500 |
| 客观曲线 | 4 条 |
| 人工听音事件 | 33 条；原有稳定 ID 全部保留 |
| 本次预处理耗时 | 约 0.7–0.8 秒（本机） |

| 800-token 压缩文本 | 约 2.3 KB |
| 网络 / 模型调用 | 0 / 0 |
| 新增付费资源 | 0 |

当前曲线：

1. 500ms RMS 响度（dBFS）。
2. 500ms 频谱质心中位数（Hz）。
3. 500ms 频谱变化量中位数。
4. 每个 500ms 窗口内，由 20ms 能量帧计算的平均正向能量变化。

近静音窗口的频谱值记为缺失，不把数值噪声当作音色证据。每条曲线同时保留物理量、0–63 分位量化值和自适应稀疏关键点。

## 明确没有做的事

- 没有从混合频谱猜测情绪。
- 没有把频谱质心称为旋律或音高。
- 没有将响度、频谱和起音强度平均成单一“综合情绪曲线”。
- 没有声称虚拟指挥轨迹来自真实指挥表演。
- 没有调用 GPT、Claude、Gemini 或其他模型进行效果测试。

当前 `melody_contour` 为 `unknown`。若以后获得可靠人声/主旋律分离轨或人工核验音符转录，再添加带休止空值、置信度和来源的旋律曲线。

## “指挥手势”启发

本轮只定义多通道代理向量：

```text
gesture[t] = [loudness, Δloudness, spectral_flux, spectral_centroid]
```

它用于提示接收端同时观察幅度、运动速度、瞬时变化和频谱位置，不将维度平均成一个数。它不是声音、情绪，也不是实际指挥手势数据。

## 声部叠层

古筝、横笛或电子琴来到前景时，不再被编码成对伴奏的替换。完整 JSON 显式保存持续基底、当前前景、基底事件引用和基底新增声部；压缩谱以 `B[...]`、`F[...]` 和 `^n>F[...]` 表示。叠层关系来自人工听音事件的重叠区间或明确的无退出交接，不凭频谱补猜乐器。

## 约 800 Token 压缩

`mss_curve_800.txt` 包含四条稀疏曲线和全部 33 条分层压缩事件。当前大小为 2,332 UTF-8 字节，代理 Token 区间为 **583–778**。

为避免只拿“曲线＋全部事件”和“只有曲线”的文字稿比较，本轮另外生成了 `natural_hybrid_800.txt`：它使用相同的四条曲线关键点，以及同一批乐器、候选、前景和动作事件，只改变表达格式。

对照：

| 表示 | UTF-8 字节 | 代理 Token |
|---|---:|---:|
| MSS/0.2 分层曲线＋事件 | 2,332 | 583–778 |
| 同证据的客观自然语言＋曲线 | 2,378 | 595–793 |
| 只有曲线的客观文字消融组 | 1,139 | 285–380 |
| MSS/0.1 自然语言事件基线 | 2,434 | 609–812 |

这些不是供应商 tokenizer 或账单数字。当前 MSS 与同证据自然语言在体积上接近，不能据此判断理解效果；MSS 的候选优势是字段边界、来源、空值、向量曲线和增量缓存布局，而不是已经证明更省 Token。

## 古筝事件完整性

当前 33 条源事件与 MSS/0.2 一一对应。古筝相关事件共 14 条，时间点或定位窗口为：

`28.490`、`53.285`、`58.795`、`64.100`、`74.316`、`86.243`、`119.138`、`127.558`、`152.761`、`158.631`、`195.413`、`199.360–200.450`、`235.060`、`242.489` 秒。

旧 12 段自然语言校对台只读取粗粒度乐器表，因此没有逐条展示这些短事件；这是展示与数据源断层，不是全部事件从详细源文件中丢失。旧页面现已明确标注为“自然语言对照基线”。

原始文字中的重复时间已经拆开：`195.413` 秒保留为古筝短暂和声；另一次短暂扬起确定在「难晓是哪一程」与「一樽江月还酹」之间，当前以 `199.360–200.450` 秒定位窗口记录。这个窗口表示待试听搜索范围，不声称古筝持续了整个区间，也不冒充已经获得精确落点。

## 首轮隔离子代理盲测

同一模型家族的三个隔离子代理分别只看到歌词、客观自然语言叠层或分层 MSS。修订后客观题加权结果为 `2.0 / 10`、`8.0 / 10`、`10.0 / 10`；分层 MSS 在本次单样本中没有发生声部引用错误。完整过程、评分和限制见 [分层 MSS 首轮盲测报告](mss-layered-blind-test-report.md)。这不是 GPT、Claude、Gemini 的跨模型验证。

## 下一轮模型实验

在相同输入预算下比较：

1. 客观自然语言。
2. 等间隔数字曲线。
3. 自适应稀疏关键点＋结构事件。

客观题检查峰谷、变化率、同步变化和时间定位；开放题允许模型自由解释，但必须区分“测量事实”和“自主联想”。回答差异更大不自动代表理解更好，应同时衡量客观准确率、幻觉率和观察/解释分离程度。

真实模型盲测仍需先报告目标模型、次数和预计费用，再申请确认。
