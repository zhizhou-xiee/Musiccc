# MSS 听音事件校对台

用于逐条试听并校对《借月》Music Semantic Score PoC 的 33 个听音事件。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:4173/tools/mss-review/>。

选择本机的 `借月MMM.mp3` 后，网页会在浏览器内计算 SHA-256，与时间轴记录的母带指纹比对。音频不会上传，也不会写进仓库。

## 校对内容

- 连续事件按起止时间循环试听；没有结束时间的点状事件自动取前 1.5 秒到后 4 秒的上下文。
- 可微调开始、结束时间，或修改事件类型、乐器、候选乐器、动作、奏法、音区、音色与中文描述。
- MSS/0.2 的四条客观曲线与事件共用同一时间轴；金色刻线显示全部古筝相关事件，状态筛选可只看这些事件。
- “持续基底与当前前景”卡片显示当前事件的叠层关系；前景乐器出现不等于伴奏退出。
- 不确定乐器应保留在“乐器候选”，不要为了填满字段强行下结论。
- 校对状态、备注和修改自动保存在当前浏览器的 `localStorage`。
- 导出文件保留稳定事件 ID、来源、审核状态和母带指纹；源数据不会被网页覆盖。

快捷键：`Space` 播放/暂停，`R` 重听，`J`/`K` 切换事件，`V` 确认并前进。

曲线来自最终 MP3 的离线自动测量，未经人工核验，也不包含情绪判断。旋律轮廓仍为未知，不使用频谱质心冒充旋律。
