# 《借月》时间轴校对台

这是一个零依赖、本地优先的人工校对工具。它以终版 MV 使用的人工波形开口标记为基准；唱完时间仍是从分离人声得到的估计。母带通过浏览器文件选择器载入，只在当前设备中解码，不会上传，也不会复制进仓库。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/tools/timeline-review/>，然后选择桌面上的 `借月MMM.mp3`。

## 校对流程

1. 逐句点击“重听本句”。播放器会在候选边界前后各保留 450 毫秒。
2. 使用按钮、毫秒输入框或快捷键调整开始与结束时间。
3. 确认无误后点击“确认并到下一句”；拿不准的句子点击“标记需复核”。
4. 随时点击“导出 JSON”。导出文件包含原始候选时间、人工时间、状态和备注。

“重置进度”只会清除当前浏览器中这首母带的校对记录；已导出的 JSON 不受影响。清除前浏览器会再次确认。

进度按母带 SHA-256 存在浏览器 `localStorage` 中；刷新页面不会丢失。清理浏览器站点数据会删除本地进度，因此每次校对结束建议导出 JSON 备份。

## 快捷键

- `Space`：播放 / 暂停
- `R`：重听当前句
- `J` / `K`：上一句 / 下一句
- `V`：确认当前句并前进
- `Cmd/Ctrl + ←/→`：开始时间 ±50 ms
- `Shift + ←/→`：结束时间 ±50 ms

## 数据原则

- 自动对齐的置信度、覆盖率与复核标记会原样保留。
- 修改过时间的已确认歌词会标记为 `manually_verified`。
- 只要仍有未确认歌词，整首歌仍为 `manual_review_in_progress`。
- 导出的段落边界会根据句级人工时间重新计算。
