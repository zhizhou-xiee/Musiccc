# 《借月》音乐摘要校对台

本工具把现有歌词、演唱者、人工乐器粗标与 MP3 母带的离线声学测量放在同一个界面中，供项目负责人逐段试听并修改面向 MCP 的音乐摘要。母带只通过浏览器文件选择器在本机读取，不会上传，也不会复制进仓库。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

打开 <http://127.0.0.1:4173/tools/summary-review/>，然后选择桌面上的 `借月MMM.mp3`。

## 校对流程

1. 选择一个段落并点击“从本段开头重听”；默认会循环当前段落。
2. 对照人工资料、自动测量和逐句歌词修改“给小机看的摘要”。
3. 确认后点击“确认并到下一段”；拿不准的内容标记为“需复核”。
4. 随时导出 `jieyue.music-summaries.reviewed.json`。下次可用“载入校对稿”继续。

修改内容和确认状态会保存在当前浏览器的 `localStorage` 中。清理浏览器站点数据会删除本机进度，因此每次校对结束建议导出 JSON 备份。

## 数据边界

- 演唱者、歌词、段落和乐器来自现有人工资料；乐器时间仍为粗粒度标注。
- 响度、动态、频谱质心、频谱变化量和人声覆盖率来自离线自动测量。
- 自动声学特征不会被用来擅自断言某件乐器出现，也不会被包装成模型直接听到了原始音频。
- 只有项目负责人确认过的段落才会导出为 `human_reviewed`；其余仍为 `draft_needs_listening_review`。

## 快捷键

- `Space`：播放 / 暂停
- `R`：从当前段落开头重听
- `J` / `K`：上一段 / 下一段
- `V`：确认当前段落并前进
